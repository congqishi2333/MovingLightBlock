# Moving Light Block / 跟随光明方块

一个极简的 NeoForge 1.21.1 模组：右键生成一个**看得见**的滚动实体，它会跟着玩家走，并且发出**真正的 Minecraft 方块光照**（不是 shader 假光、不改画面颜色）。

## 功能

- 在创造模式物品栏 **Tools & Utilities** 里找到「跟随光明方块」，也可以 `/give movinglightblock:moving_light`
- **右键**物品（对着方块或空中都可以）生成一个实体；创造模式下不会消耗物品
- 实体优先跟随生成它的玩家；该玩家不在线时跟随最近玩家；换维度时实体会跟着过去
- 玩家先走开 **3 格**后实体才开始追赶；追到距离玩家 **2 格**时停下，不会贴着玩家挡操作
- 追赶速度默认 **5.6 格/秒**（约等于跑步速度），并且**允许飞行**，可以跨地形/上下追
- 可见实体像《半条命》伙伴方块一样**滚动行走**：按自身实际位移累计翻滚角度，纯动画，无碰撞、无物理
- 每个实体背后有一个**不可见**的隐藏方块，只负责提供真实方块光照；所以不会看到两个方块
- 隐藏方块**无碰撞**、**不可破坏**，玩家退出时实体会被移除并还原原本方块
- 只替换「可被替换」的格子（空气、水、草等），不会凭空覆盖箱子或基岩
- 方块光照本身是网格化计算的，所以光照会按格跳转；可见实体的移动/翻滚是平滑的

> 1.2.0 起不再自动给每个玩家生成方块，改为由物品右键生成实体。
> 1.3.0 起实体不再贴着玩家：玩家走开 3 格后才起飞追赶，追到 2 格处停下。

## 配置

配置文件：`config/movinglightblock-common.toml`（首次启动自动生成）

| 配置项 | 默认 | 说明 |
|---|---:|---|
| `enabled` | `true` | 总开关 |
| `animation` | `true` | 滚动行走动画；`false` 则保持直立跟随 |
| `lightLevel` | `15` | 真实光照等级，`0`~`15`（15 = 萤石/海晶灯） |
| `yOffset` | `0` | 相对被跟随玩家脚下方块的 Y 偏移；`0` 脚下，`1` 头顶，`2` 头顶上方 |
| `followDistance` | `3.0` | 玩家离开多远后实体开始追赶（格） |
| `stopDistance` | `2.0` | 追到多近时停下，避免贴脸挡操作（格） |
| `chaseSpeed` | `5.6` | 追赶速度，格/秒；默认约等于跑步速度 |

保存配置文件后游戏内 `/reload` 即可生效；模组会清掉旧光块并在下一 tick 用新亮度重新放置。

## 和 HandLightOnly 光影的区别

- **HandLightOnly**：只在 `final.fsh` 里做屏幕后处理叠加，零模组、零几何 pass，不产生真实光照
- **本模组**：放置真实方块光源，能被 Iris/原版光照引擎、实体光照、红石等正常读取；但会占用一个方块格

## 构建

```powershell
.\gradlew.bat build
```
