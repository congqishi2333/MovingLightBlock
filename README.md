# Moving Light Block / 跟随光明方块

一个极简的 NeoForge 1.21.1 模组：一个**看得见**的发光方块跟着每个玩家移动，并且发出**真正的 Minecraft 方块光照**（不是 shader 假光、不改画面颜色）。

## 功能

- 每个玩家身边各有一个方块，按玩家所在方块位置移动（方块光照本身是网格化计算的，所以移动时会按格跳转，这是原版机制决定的）
- 可见的方块会像《半条命》伙伴方块一样**滚动行走**：按玩家位移累计翻滚角度，纯动画，无碰撞、无物理
- 真正发光的方块本体是不可见的，只用实体渲染出可动画的外观，所以不会看到两个方块
- 方块**无碰撞**，不会挡路、不会把玩家顶起来
- 方块**不可破坏**，玩家离开、换维度、退出服务器时会自动移除并还原原本方块
- 只替换「可被替换」的格子（空气、水、草等），不会凭空覆盖箱子或基岩
- 在创造模式物品栏 **Tools & Utilities** 里有一块「跟随光明方块」，也可以 `/give movinglightblock:moving_light`

## 配置

配置文件：`config/movinglightblock-common.toml`（首次启动自动生成）

| 配置项 | 默认 | 说明 |
|---|---:|---|
| `enabled` | `true` | 总开关 |
| `animation` | `true` | 滚动行走动画；`false` 则保持直立跟随 |
| `lightLevel` | `15` | 真实光照等级，`0`~`15`（15 = 萤石/海晶灯） |
| `yOffset` | `0` | 相对玩家脚下方块的 Y 偏移；`0` 脚下，`1` 头顶，`2` 头顶上方 |

保存配置文件后游戏内 `/reload` 即可生效；模组会清掉旧光块并在下一 tick 用新亮度重新放置。

## 和 HandLightOnly 光影的区别

- **HandLightOnly**：只在 `final.fsh` 里做屏幕后处理叠加，零模组、零几何 pass，不产生真实光照
- **本模组**：放置真实方块光源，能被 Iris/原版光照引擎、实体光照、红石等正常读取；但会占用一个方块格

## 构建

```powershell
.\gradlew.bat build
```
