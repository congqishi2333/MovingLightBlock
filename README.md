# Moving Light Block / 跟随光明方块

一个极简的 NeoForge 1.21.1 模组：右键生成一个**看得见**的滚动实体，它会跟着玩家走，并且发出**真正的 Minecraft 方块光照**（不是 shader 假光、不改画面颜色）。

## 功能

- 在创造模式物品栏 **Tools & Utilities** 里找到「跟随光明方块」，也可以 `/give movinglightblock:moving_light`
- **右键**物品（对着方块或空中都可以）生成一个实体；创造模式下不会消耗物品
- **每个玩家同时只能有 1 个召唤物**；再次右键会替换掉原来的那个，不会叠加
- 实体优先跟随生成它的玩家；该玩家不在线时跟随最近玩家；换维度时实体会跟着过去
- 生成后玩家**首次累计移动 3 格**实体才开始追赶；之后只要玩家离开 **2 格**就立刻继续跟随，不会反复停走
- 追赶由玩家的实际移动触发，所以实体落地后不会因为高度差把自己重新“解锁”并弹回玩家身边
- 追赶速度默认 **5.6 格/秒**（约等于跑步速度），并且**允许飞行**，可以跨地形/上下追
- 玩家停下来后实体会**受重力落回地面**；再次走远时它会重新起飞追赶
- 实体离玩家超过 **12 格**会被**强制传送回玩家附近**；卡进完整方块里也会自动脱困，不会再一路向上穿墙飞走
- 实体是**完全无敌**的：仙人掌、岩浆块、尖刺、火焰、爆炸、摔落、流体、活塞、压力板等所有伤害/触发路径都被阻断，站在伤害方块上也不会被弹走或瞬移
- 可见实体像《半条命》伙伴方块一样**滚动行走**：按自身实际位移累计翻滚角度
- 可通过配置 `passThroughWalls` 选择是否穿墙：**默认可穿墙**；设为 `false` 后会与方块碰撞，但仍然不会挡住/推动玩家
- 梯子攀爬暂未实现；关闭穿墙后遇到梯子或竖直墙面会停在前面
- 每个实体背后有一个**不可见**的隐藏方块，只负责提供真实方块光照；所以不会看到两个方块
- 隐藏方块**无碰撞、无选中箱、不可破坏**：玩家既看不到也选不中/摸不到；如果往它的位置放方块会直接替换它，光照下一 tick 自动挪到附近空格
- 只替换「可被替换」的格子（空气、水、草等），不会凭空覆盖箱子或基岩
- 遇到台阶、楼梯、栅栏、雪层等**不完整方块**时会在附近空格找位置；暂时找不到也会保留已有光源，不会突然熄灯
- 方块光照本身是网格化计算的，所以光照会按格跳转；可见实体的移动/翻滚是平滑的

## 配置

配置文件：`config/movinglightblock-common.toml`（首次启动自动生成）

| 配置项 | 默认 | 说明 |
|---|---:|---|
| `enabled` | `true` | 总开关 |
| `animation` | `true` | 滚动行走动画；`false` 则保持直立跟随 |
| `passThroughWalls` | `true` | 是否允许穿过方块；`false` 会与方块碰撞，但仍不会挡住玩家 |
| `lightLevel` | `15` | 真实光照等级，`0`~`15`（15 = 萤石/海晶灯） |
| `yOffset` | `0` | 相对被跟随玩家脚下方块的 Y 偏移；`0` 脚下，`1` 头顶，`2` 头顶上方 |
| `followDistance` | `3.0` | 玩家首次累计移动多远后实体开始追赶；之后持续跟随（格） |
| `stopDistance` | `2.0` | 追到多近时停下，避免贴脸挡操作（格） |
| `chaseSpeed` | `5.6` | 追赶速度，格/秒；默认约等于跑步速度 |
| `teleportDistance` | `12.0` | 离玩家超过这个距离就强制 TP 回玩家附近（格） |

保存配置文件后游戏内 `/reload` 即可生效；模组会清掉旧光块并在下一 tick 用新亮度重新放置。

## 自定义实体材质（标准资源包，无需改模组）

实体直接用原版方块模型系统渲染 `movinglightblock:moving_light_visual`，所以任何标准资源包都能改它的外观。

- 完整格式、固定路径和限制说明：[CUSTOMIZATION.md](CUSTOMIZATION.md)（含 `rolling.json`：固定轴、自由轴 `[x,y,z]`、XYZ 三轴欧拉、开关和速度）
- 可直接复制使用的资源包模板：[example-resourcepack/](example-resourcepack/)

最简单的做法是覆盖贴图：

```text
assets/movinglightblock/textures/block/moving_light.png
```

游戏内 `F3 + T` 重载资源包即可生效。

## 和 HandLightOnly 光影的区别

- **HandLightOnly**：只在 `final.fsh` 里做屏幕后处理叠加，零模组、零几何 pass，不产生真实光照
- **本模组**：放置真实方块光源，能被 Iris/原版光照引擎、实体光照、红石等正常读取；但会占用一个方块格
